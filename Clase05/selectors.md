
# Selectores CSS - Calculadora Modular

Este documento contiene los selectores CSS de los elementos
de nuestra calculadora para futuras pruebas con Selenium.

| Elemento | Atributo usado | Selector CSS |
|---|---|---|
| Título principal | id | #titulo-principal |
| Formulario | id | #form-calculadora |
| Primer número | id | #num1 |
| Segundo número | id | #num2 |
| Operación sumar | id | #sumar |
| Operación restar | id | #restar |
| Operación multiplicar | id | #multiplicar |
| Operación dividir | id | #dividir |
| Botón Calcular | id | #btn-calcular |
