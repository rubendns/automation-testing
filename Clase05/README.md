
# Clase 5 - Calculadora Modular

## Descripción

Página web estática de una calculadora modular,
desarrollada con HTML y CSS.

La calculadora permite ingresar dos números y
seleccionar una operación: sumar, restar,
multiplicar o dividir.

Por el momento no realiza cálculos, ya que
esta actividad no utiliza JavaScript.

## Archivos

- index.html: estructura de la calculadora.
- estilos.css: diseño visual de la página.
- selectors.md: selectores CSS para futuras pruebas.

## Cómo ejecutar

1. Abrir la carpeta Clase05.
2. Hacer doble clic en index.html.
3. La calculadora se abrirá en el navegador.

## Cómo verificar

1. Comprobar que aparezcan los dos campos numéricos.
2. Verificar que se pueda seleccionar una operación.
3. Comprobar que aparezca el botón Calcular.
4. Abrir DevTools con F12.
5. En la consola, ejecutar:

   document.querySelector('#num1')

6. Verificar que se encuentre el campo del primer número.

### ¿Qué diferencia hay entre `README.md` y `selectors.md`?

**`README.md`** explica qué es el proyecto, cómo abrirlo y cómo comprobar que funciona.

**`selectors.md`** documenta los identificadores que usaremos en futuras pruebas automatizadas con Selenium.

Aunque ambos son archivos Markdown, tienen propósitos diferentes.
